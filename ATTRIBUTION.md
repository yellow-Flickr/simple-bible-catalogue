# Sources and attribution

Many Bible versions in this catalogue are sourced from or prepared using the
repositories below. We are grateful to their maintainers and contributors for
making Bible data available to the community.

| Source | Repository | Notes |
| --- | --- | --- |
| Beblia | [Holy-Bible-XML-Format](https://github.com/Beblia/Holy-Bible-XML-Format) | A collection of Bible translations in XML. |
| Sajeeva Vahini | [bibles](https://github.com/sajeevavahini/bibles) | Bible data in XML and other database formats; the repository describes Telugu and English Lo Telugu resources. |

These are source repositories, not blanket copyright or redistribution grants.
The repositories do not declare a repository-wide license in their GitHub
metadata, and source texts may have terms that differ by translation. Before
including a version, check the source file's notices and the translation's
rights, preserve required attribution, and confirm that redistribution in the
app is permitted. If rights or attribution requirements are unclear, do not
publish the version until they have been resolved.

## Version-level source records

When a version's origin is known, record the exact upstream file or edition,
link, and any required credit/license in that version's catalogue entry or in
the table below. Do not infer a version's source solely from its language or
name.

| Catalogue version | Upstream file or edition | Required attribution / rights notes |
| --- | --- | --- |
| AMPC — Amplified Bible Classic Edition | [Amplified Bible (1965).xml](https://github.com/sajeevavahini/bibles/blob/main/Amplified%20Bible%20(1965).xml) | Source file identified; verify and preserve any translation-specific attribution and redistribution terms. |
| AMP — Amplified Bible | [EnglishAmplifiedBible.xml](https://github.com/Beblia/Holy-Bible-XML-Format/blob/master/EnglishAmplifiedBible.xml) | Source file identified; verify and preserve any translation-specific attribution and redistribution terms. |

## Adding another source

Add a row to the source table above with the maintainer/organization name,
canonical repository link, and a short factual description. Also record
version-specific origins and rights in the version-level table. Keep source
credit separate from copyright ownership: crediting a data repository does
not replace any notice required by the Bible translation's rights holder.
